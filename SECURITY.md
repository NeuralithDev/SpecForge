# Security Policy

## Supported Versions

SpecForge Studio provides security fixes for the latest published releases.

| Version | Supported          |
| ------- | ------------------ |
| 5.0.x   | :white_check_mark: |
| < 5.0   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability in SpecForge Studio, please do not disclose it publicly on GitHub issues.

Instead, please report vulnerabilities by opening a private advisory under the repository's **Security** tab at:
[https://github.com/NeuralithDev/SpecForge/security/advisories](https://github.com/NeuralithDev/SpecForge/security/advisories)

Include the following details in your report:
- Type of issue (e.g. SSRF bypass, credential scrubber evasion, prototype pollution)
- Clear reproduction steps or proof-of-concept
- Any relevant logs, payloads, or environmental details

The Neuralith team will acknowledge the vulnerability report, evaluate its impact, and coordinate a fix promptly.
