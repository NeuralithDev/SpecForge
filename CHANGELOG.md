# Changelog

All notable changes to **SpecForge Studio** will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [5.0.0] - 2026-10-18

### Added
- **SpecForge Studio IDE**: Local-first API client featuring a split-pane layout, full-width request header, multi-tab execution, and IndexedDB client-side persistence.
- **Industrial Architectural Experience**: Grid system, orbital canvas, and editorial typography.
- **Zero-Leakage `.har` Sanitizer**: In-memory token, cookie, and authorization header scrubbing prior to collection synthesis.
- **Deterministic Claude & Cursor MCP Compiler**: Automatic synthesis of `@modelcontextprotocol/sdk` servers with strict Zod schema validation and JSON-RPC 2.0 stdio handlers.
- **TypeScript SDK & Vitest Parity Generator**: 1-click export of typed fetch clients, OpenAPI 3.1 specifications, and executable contract parity tests.
- **Script-Free Variable Chaining**: Direct response payload field extraction (`id`, `token`, `cursor`) into environment variables without boilerplate pre-request JavaScript.
- **SSRF-Guarded Security Proxy**: Private RFC 1918 IPv4 ranges, loopbacks, and cloud metadata addresses (`169.254.169.254`) blocked by default.
- **Enterprise Capacity & Billing**: Integrated Razorpay and Stripe checkout gateways with generous tier quotas (25 endpoints free forever).
